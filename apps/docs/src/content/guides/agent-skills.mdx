title: Agent skills

---

A skill is a folder of instructions (`SKILL.md` and its references) that a coding agent loads when
a task calls for it. contentworker publishes three for developers building on a workspace, in the
`skills/` folder of the [contentworker repository](https://github.com/contentworker/contentworker):

| Skill                                  | For                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------ |
| `building-on-contentworker`            | Choosing an SDK, Delivery or Preview, writes and read-your-writes, generated types, rendering rich text and embeds, caching |
| `modeling-content-with-contentworker`  | Field types, components, repeaters and blocks, validations, localization, and the model as a file with `contentworker model apply` |
| `migrating-to-contentworker`           | Importing a WordPress export, CSV or JSON: mapping, rich text conversion, dry runs, publishing and checking the result |

They tell the agent to use the [CLI](/guides/cli/) and the [SDKs](/guides/sdks/), and link these
docs for detail. Every command, flag and SDK method they name is checked against the code when it
changes, so a skill doesn't drift from the tools it describes.

These are separate from the skills the [MCP server](/guides/mcp/#skills) serves, which guide an
agent working *inside* a workspace through MCP tools.

## Install

With the open `skills` CLI, which works with Claude Code and other agents:

```sh
npx skills add contentworker/contentworker@building-on-contentworker
npx skills add contentworker/contentworker@modeling-content-with-contentworker
npx skills add contentworker/contentworker@migrating-to-contentworker
```

Add `-g` to install for your user rather than the project.

Or copy the folders yourself. For Claude Code, a project's skills live in `.claude/skills/` and
your own in `~/.claude/skills/`:

```sh
git clone --depth 1 https://github.com/contentworker/contentworker /tmp/contentworker
mkdir -p .claude/skills
cp -R /tmp/contentworker/skills/* .claude/skills/
```

Commit them to share with your team. To update, copy them again (or `npx skills update`).

## Give the agent access

The skills expect the CLI to be installed and signed in:

```sh
npm install -D @contentworker/sdk
npx contentworker login --url https://api.your-workspace.contentworker.app
npx contentworker doctor
```

For an agent that runs unattended, set `CONTENTWORKER_TOKEN` and `CONTENTWORKER_URL` to a
[key](/guides/api-keys/) with only the scopes the task needs: `preview:read` to read and generate
types, `content:write` to create entries and import, `content:publish` to publish, and
`content:manage` to change the content model. The agent can do exactly what that key can.
