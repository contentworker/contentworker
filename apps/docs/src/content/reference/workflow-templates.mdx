Each template is an ordinary workflow: start from one, change any node, and publish it as your own.
This page is generated from the templates themselves when the docs are built. Each template's
anchor is its id, and each node links to its entry in the [node catalog](/reference/nodes/).

A template marked **gates publish** sets the workflow's `gatesPublish` flag: once you publish the
workflow, the entries it covers publish only from one of its runs, and every other publish (the
admin's **Publish**, the API, MCP, bulk, releases and scheduled publishes) is refused with
`409 publish_gated`. See [Gate publishing](/guides/workflows/#gate-publishing).
